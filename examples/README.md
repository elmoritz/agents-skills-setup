# examples/ — one runnable project per config flavor

Generated by `scripts/gen-examples.sh` (a headless, non-interactive `/ticket:init`
via `scripts/te-scaffold.sh`). Each directory is a **complete, valid** project for
one flavor of `.claude/config.yaml`, so you can verify the setup, do dry-runs, and
exercise the workflow without walking init's interactive gates.

These are **template/test infrastructure** — like `tests/`, they are NOT copied
into a user's project. Regenerate with `scripts/gen-examples.sh`; CI fails if the
committed tree drifts from the generator.

## The matrix (18 valid flavors)

Config-invalid combinations are excluded by construction: `projects.enabled: true`
and native milestones are github-only; tracker milestones are filesystem-only.

| Backend | Milestones | Inbox | Projects | Flavors |
| --- | --- | --- | --- | --- |
| filesystem | `auto`→trackers / `labels` / `none` | ×{yes,no} | always off | 6 |
| github | `auto`→native / `labels` / `none` | ×{yes,no} | ×{on,off} | 12 |

## Trying one

**Filesystem** flavors are fully self-contained (config + stage folders + ledger +
seeded tickets + template) — the read path works immediately:

```sh
cd examples/fs-trackers-inbox
../../.claude/scripts/te list pickable
../../.claude/scripts/te read TE-001
../../.claude/scripts/te milestone scan
```

**GitHub** flavors carry only `.claude/config.yaml` — issues, workflow labels, and
(where enabled) the Projects v2 board live on GitHub, created by `/ticket:init`'s
side effects and `te`'s write path. Validate the config with:

```sh
cd examples/gh-native-proj
../../.claude/scripts/te config validate
```

The github read/list/milestone/projects **mapping** is tested offline against
recorded fixtures in `tests/fixtures/gh/`; it is verified **live** against a
throwaway repo by `scripts/live-gh-check.sh` (needs `gh` auth + a `project`-scoped
token — not CI-runnable).

## Automated verification

`scripts/test-examples.sh` validates every flavor and smoke-runs the read path on
the seeded filesystem flavors (offline, CI-runnable).
